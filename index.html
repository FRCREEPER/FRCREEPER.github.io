使用说明

1. 下载文件全部为 base64 文本（对齐 Causenix 未来经 HTTP 拉取后的解析格式）。解码得到 ELF：

base64 -d myos.elf.b64 > myos.elf
base64 -d desktop.elf.b64 > desktop.elf

2. 运行内核（需要 Limine 引导 + QEMU）：

qemu-system-x86_64 -machine q35 -m 512M -cdrom myos.iso
# 或硬盘引导：boot.img 已含 Limine + /boot/myos.elf

3. 网络栈（V3）实测命令——host 发 UDP 到 guest 7001 端口，内核直接执行 shell 命令：

qemu ... -netdev user,id=n1,hostfwd=tcp::7000-:7000,hostfwd=udp::7001-:7001 -device e1000,netdev=n1

# host 侧：
python3 -c 'import socket;s=socket.socket(socket.AF_INET,socket.SOCK_DGRAM);s.sendto(b"echo V3-FROM-NET",("127.0.0.1",7001))'
  • 内置命令白名单：help / echo / version / mem / pwd / clear / ls / cat / fsck / gc / mount / mkdir / rm / tree / cd
  • 程序类命令（desktop 等）会被拦截——避免中断上下文切用户态
